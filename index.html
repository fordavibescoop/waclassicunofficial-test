About

This is a modification of Aronski’s original iOS 4–6 WA-Classic project. It still uses the same bridge and underlying components as Aronski’s app; only the compatibility layer has been changed so it runs on iOS 7–10 (32/64-bit). Everything here is free and stays free. The app installs into /Applications: do not keep a WhatsApp Classic IPA sideloaded at the same time as the package from here. An arm64 build for iOS 15+ rootless jailbreaks keeps the same iOS 6 look.
